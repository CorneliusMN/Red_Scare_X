# Red_Scare_X
To run our code clone the repository and navigate to the code folder. Then run the python file for each problem with:
```bash
python "[PROBLEM NAME].py" # with [PROBLEM NAME] being for example "few"
```
This produces a txt file in the results folder containing the results for that specific problem. 
To combine all the results into one results.txt file navigate to the results folder. 
Here you just need to run the table_results.py using:
```bash
python table_results.py
```
Which will create the folder containing all the results.
